SQL → SQL Taşıyıcı

Şu an desteklenen: SQL Server → PostgreSQL

1 Kayıtlı sunucular

Sunucular yalnızca bu bilgisayarda saklanır. Şifreler makineye bağlı anahtarla şifrelenir.

Sunucu ekle / düzenle

2 Kaynak

Birden çok veritabanı seçebilirsin; hepsi sırayla taşınır. Biri başarısız olursa kalanlar devam eder.

Kaynak veritabanı Hedef adı

Önce bir SQL Server seç — veritabanları buraya gelir.

3 Hedef

{db} kaynak veritabanının adıyla değişir — örneğin {db}_pg. Listedeki her hedef adını tek tek de düzenleyebilirsin. Var olmayan ad doğru collation ile oluşturulur, var olana dokunulmaz. Hedef tablolar önceden var olmalıdır — eksik olanları aşağıdaki aynala seçeneği kaynaktan oluşturur.

4 Seçenekler

Hepsi kapalıdır ve bilinçli açılır. Ne geçirdiklerini okumadan açmak, bu aracın var oluş sebebini iptal eder.
